============================================================
1. HACKATHON IDENTITY
============================================================

NAME:

GIT.COMMIT.PUSH

Core concept:

THE UNINVENTED

Primary philosophy:

"Build What Doesn't Exist Yet."

The hackathon consists of three stages:

GIT INIT
Online qualification round.

Teams submit their initial ideas/prototypes and compete for selection.

GIT COMMIT
Offline 24–36 hour physical hackathon in Nagpur, India.

Selected teams come physically to Nagpur and build, test, break, iterate and
present their solutions under time pressure.

GIT PUSH
The final 3 teams travel to Bangkok, Thailand.

They pitch their innovations to industry/international audiences.

Narrative:

GIT INIT
= Start the idea.

GIT COMMIT
= Build the idea.

GIT PUSH
= Take the idea to the world.
